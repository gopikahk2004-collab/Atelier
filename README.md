# ATELIER LUXE | Virtual Dressing Room & Haute Couture E-Commerce

A luxury, interactive e-commerce web application featuring a real-time virtual fitting & dressing room engine, AI styling assistant, customizable mannequin avatar, dynamic garment layering, product catalog, cart drawer, and express checkout.

![ATELIER LUXE Banner](assets/images/hero_banner.jpg)

- **Interactive Virtual Fitting Room**:
  - Customizable 2D/SVG model (skin tones, hair styles, poses).
  - Multi-layer garment dressing engine (Tops, Bottoms, Outerwear, Dresses, Shoes, Accessories).
  - Real-time garment fitting with drape simulation, color swatch tinting, and size fit tension (XS to XL).
  - Studio ambiance lighting switcher (Golden Hour, Runway Spotlight, Studio Minimal, Cyberpunk Neon).
  - "Style with AI" instant outfit recommendation generator.
  - "Add Entire Look to Cart" with bundle discount.
  - Snapshot & Lookbook builder to save and re-wear favorite combinations.

- **E-Commerce Catalog**:
  - Editorial product gallery with high-resolution photography.
  - Instant "Try On In Dressing Room" direct action.
  - Category, price, and occasion filtering with live search.
  - Detailed product modal with fabric composition and size guide.

- **Shopping Cart & Checkout**:
  - Animated slide-over shopping bag drawer.
  - Real-time subtotal, taxes, and free shipping progress meter.
  - Promo code discounts (use code `VOGUE15`).
  - Express multi-step checkout with simulated order confirmation receipt.

## 🚀 Quick Start

Run the application locally using Python's built-in HTTP server:

```bash
# Navigate to the project directory
cd /Users/kgopikavikas/.gemini/antigravity-ide/scratch/ecommerce-dressing-room

# Start local server
python3 -m http.server 3000
```

Open your browser and navigate to:
```
http://localhost:3000
```

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup.
- **Vanilla CSS3**: Design system with CSS custom properties, glassmorphism, micro-animations, and responsive layout.
- **Vanilla JavaScript (ES6+)**: Modular state management, dynamic SVG layer rendering engine, cart storage, and UI controllers.
- **Google Fonts**: *Cinzel* & *Plus Jakarta Sans*.
